# What is an LLM?

A Large Language Model (LLM) is an AI model trained on massive amounts of text data that can understand and generate human-like responses.

LLMs can perform tasks such as:

- Answering questions
- Summarizing documents
- Writing code
- Generating content
- Translating languages
- Extracting information

### Example

**User**

```text
What is Azure AI Search?
```

**Assistant**

```text
Azure AI Search is a cloud-based search service that provides full-text, vector, and hybrid search capabilities.
```

---

# What is a Chat Completion API?

A Chat Completion API allows applications to interact with an LLM using a conversational format.

Instead of sending a single text prompt, applications send a collection of messages representing a conversation.

### Example

```text
User: What is Azure?

Assistant: Azure is Microsoft's cloud platform.

User: What services does Azure provide?

Assistant: Azure provides compute, storage, networking, AI, security, and many other cloud services.
```

The model uses the conversation history to generate contextual responses.

---

# Understanding Message Roles

Chat-based LLM applications typically use three message roles.

---

## System Message

The system message defines the behavior, personality, or expertise of the AI assistant.

### Example

```text
You are an Azure Cloud Architect.
```

This instruction guides how the model should respond.

---

## User Message

The user message contains the actual question or request.

### Example

```text
Explain Azure Functions.
```

---

## Assistant Message

The assistant message represents a previous response generated by the model.

### Example

```text
Azure Functions is a serverless compute service offered by Microsoft Azure.
```

Assistant messages help maintain conversation context.

---

# Message Flow

```text
System Message
       ↓
User Message
       ↓
      LLM
       ↓
Assistant Response
```

### Example

```text
System:
You are a Cloud Solution Architect.

User:
Explain Azure Kubernetes Service.

Assistant:
Azure Kubernetes Service (AKS) is a managed Kubernetes platform provided by Microsoft Azure.
```

# Understanding Temperature

Temperature controls how creative or deterministic the model's responses are.

---

## Low Temperature (0.0 - 0.3)

Best for:

- Enterprise applications
- Question answering
- Technical assistance
- Consistent outputs

Example:

```python
temperature = 0.0
```

Characteristics:

- More predictable
- Less variation
- More deterministic

---

## Medium Temperature (0.5 - 0.7)

Best for:

- General chatbots
- Virtual assistants
- Everyday conversations

Example:

```python
temperature = 0.7
```

Characteristics:

- Balance between creativity and consistency

---

## High Temperature (0.8 - 1.0)

Best for:

- Content creation
- Creative writing
- Brainstorming ideas

Example:

```python
temperature = 1.0
```

Characteristics:

- Highly creative
- More variation between responses

# Prompt Engineering Basics

Prompt Engineering is the practice of writing effective instructions that help the LLM generate better responses.

Better prompts typically produce better output.

---

## Example 1: Basic Prompt

```text
Explain Azure Storage.
```

---

## Example 2: Improved Prompt

```text
Explain Azure Blob Storage for a beginner using five bullet points.
```

The second prompt is more specific and usually generates a better response.

---

# Prompt Engineering Best Practices

## Be Specific

Instead of:

```text
Explain Kubernetes.
```

Use:

```text
Explain Kubernetes in simple terms for a DevOps beginner.
```

---

## Define the Output Format

Instead of:

```text
Explain Docker.
```

Use:

```text
Explain Docker in 5 bullet points.
```

---

## Define the Audience

```text
Explain Azure Networking to a Cloud Engineer.
```

or

```text
Explain Azure Networking to a beginner with no cloud experience.
```

The model tailors its response based on the audience.
